Виселица: английские слова: файлы для установки

1. Выложи всю эту папку на любой бесплатный HTTPS-хостинг (например GitHub Pages или Netlify).
2. Открой адрес в Chrome на телефоне: меню ⋮ -> "Установить приложение" / "Добавить на главный экран".
3. Для настоящего APK: вставь адрес сайта в pwabuilder.com и выбери Android.
Игра работает без интернета после первого открытия.
