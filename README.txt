Виселица: английские слова

Как обновить игру на GitHub:
1. Открой репозиторий -> Add file -> Upload files.
2. Перетащи ВСЕ файлы из этой папки (не саму папку): index.html, manifest.webmanifest, sw.js, три иконки.
3. Подтверди замену файлов (Commit changes).
4. Подожди 1-2 минуты. Если на телефоне видна старая версия, закрой и снова открой приложение.
